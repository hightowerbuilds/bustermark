## Found while running

- **App fix:** typing straight into a new note could raise the "changed on disk"
  dialog. `create_file` is not covered by the watcher's self-save window, and macOS
  reported the creation after the watch began, so the empty file looked like an
  outside edit against a dirty editor. `ipc.ts` now remembers what the app last
  read, wrote, or created at each path, and the watcher ignores a change whose
  content matches. Test in `file-watcher.test.ts`.
- Harness: the hard-break step pressed Shift+Enter in the same tick as typing,
  before ProseMirror had read the text, which lost the first line. It now waits a
  frame.
- Harness: the first-frame check held the enlarged target word to 1px snapped,
  while the emphasis check (added 10-17) allows it 1.5px. The enlarged word
  measured 1.09px. The first-frame check now leaves that word to the emphasis
  check. The full Spread check had likely not been run since emphasis was added.
